## Core message

**Run payments, spend, NRS e-invoicing and treasury from one platform.**

Built from Duplo's own words:
- Headline: "The financial operating system for African businesses" [voice]
- Subheadline: "all from one unified platform built for scale." [voice]
- CEO: "the single operational layer that finally connects payments, invoicing and tax logic." [voice]
